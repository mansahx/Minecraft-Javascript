# MENKREP 0.0.1 Alpha by Kelompok 8bit

> **Important Note:**  
> This game is developed **solely for a final academic project** (Kelompok 8bit). Fan recreation for educational and academic project purposes only. Not affiliated with Mojang AB or Microsoft.

---

A from-scratch recreation of MENKREP in HTML5 (Three.js + WebGL2).  
Every texture, sound, font glyph, HUD sprite, and mob skin is generated procedurally in code at startup, so the entire game runs directly from `Minecraft.html` with no extra downloads or server required.

## How to Play

Open or double-click `Minecraft.html` (Google Chrome or Microsoft Edge recommended). No additional installation required.  
Worlds save automatically to your browser (autosave occurs every minute, on pause, and on quit).

## Controls

| Action | Key |
| --- | --- |
| Move / Jump / Sneak / Sprint | `W` `A` `S` `D` / `Space` / `Left Shift` / `Left Ctrl` |
| Mine / Place / Pick block | Left / Right / Middle mouse button |
| Hotbar selection | `1`-`9`, Mouse wheel |
| Inventory / Drop item / Swap offhand | `E` / `Q` / `F` |
| Chat / Command | `T` / `/` (`/help` lists available commands) |
| Toggle HUD / Debug info / Fullscreen | `F1` / `F3` / `F11` |
| Fly (Creative Mode) | Double-tap `Space` |
| Pause Menu | `Esc` |

## Game Features

- **Title Screen**: Rotating live cherry-grove 3D panorama, splash text, Options, Language, Accessibility, Multiplayer/Realms menus, and World Creation/Selection.
- **Infinite Procedural World**: Multi-biome generation including plains, forest, birch forest, taiga, snowy plains, desert, savanna, jungle, swamp, meadow, windswept hills, snowy slopes, cherry grove, beaches, rivers, oceans, caves, ores, flora, and structures.
- **Lighting & Atmosphere**: Chunked terrain with sky/block lighting, smooth lighting, ambient occlusion, fog effects, animated water/lava, and realistic day/night cycles with sun, moon, and drifting 3D clouds.
- **Survival System**: Health, hunger, drowning, environmental damage, XP levels, death and respawn system, 2x2 and 3x3 crafting, furnace smelting, container storage, TNT physics, and plant growth mechanics.
- **Creative Mode**: Full tabbed creative inventory (Construction, Equipment, Items, Nature, Search), instant block mining, and flight mode.
- **Mobs & AI**: Pigs, cows, sheep, chickens, zombies, skeletons (with archery AI), creepers (with explosion mechanics), and spiders. Complete with natural day/night spawning, daylight burning, item drops, and XP orbs.
- **Audio Engine**: Synthesized sound effects (material digging/steps, UI interaction, damage, eating, mobs, explosions) and generative procedural ambient music.
